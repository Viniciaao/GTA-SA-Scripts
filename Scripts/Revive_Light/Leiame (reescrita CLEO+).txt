JESUS ENFERMEIRO - reescrita em gta3script (CLEO 4.4.4 + CLEO+)
================================================================
Mod original: Junior_Djjr (MixMods).
Codigo antigo (decompilado): "CLEO/Jesus Enfermeiro (Junior_Djjr).txt".
Proper Shaders API: luz per-pixel deferred (opcional).

INSTALACAO
----------
1. Tenha o CLEO 4.4.4 (ou superior) e o CLEO+ 1.2.0+ (cleo.li) instalados.
2. Copie para a pasta CLEO do GTA San Andreas:
       Jesus Enfermeiro.cs      (script compilado - e o que o jogo usa)
       Jesus Enfermeiro.ini     (configuracao + lista de peds)
   Usando ModLoader: jogue os dois arquivos na pasta do mod.
3. (Opcional, recomendado) Proper Shaders com a API publica
   (ProperShaders.asi, versao 09-26+). Sem ele o mod funciona igual ao
   vanilla (searchlight/corona). Com ele, a luz vira per-pixel de verdade
   e ilumina parede, chao, CJ, fog etc.
   Docs da API: https://github.com/MixMods/ProperShadersApiExample
4. "Jesus Enfermeiro.sc" e o codigo-fonte (gta3script). Nao precisa compilar
   nada para jogar (se o .cs ja estiver atualizado).

O QUE MUDOU
-----------
- Os peds vem do INI por NOME de modelo, nunca por ID: funciona tambem com
  peds adicionados que nao substituem nenhum original (ModLoader / .ide).
  O script antigo so conhecia 3 IDs fixos (LAEMT1, SFEMT1, LVEMT1).
- Varios NPCs iluminados ao mesmo tempo (o antigo iluminava um por vez).
- A luz apaga na hora em que o NPC morre - e tambem quando o ped e deletado
  ou sai da pool (streaming). O antigo nao checava nada disso.
- Nada de varrer a heap na mao (0xB74490 + byte map) em todo quadro: a
  enumeracao usa a pool oficial de pedes do CLEO+ e a comparacao e feita
  pelo ID resolvido a partir do NOME (CLEO+ GET_MODEL_BY_NAME).
- Protecao contra o bug do jogo que escreve fora do array de searchlights
  quando acaba a vaga (veja "MaxLights" no INI).
- Dois tipos de luz vanilla, configuraveis: facho de searchlight (igual ao
  original) e/ou brilho (corona com cor e tamanho proprios).
- INTEGRACAO COM PROPER SHADERS (UseProperShaders=1):
    * Resolve em runtime PS_LightCreate / PS_LightDestroy /
      PS_LightSetPosition de ProperShaders.asi (mesmo padrao do Soundize).
    * Cria luz ponto (ou spot) per-pixel no peito do NPC e move todo quadro.
    * Cor vem de Color= R G B; raio/intensidade/fog de PsRadius/PsIntensity/
      PsFog/PsOffsetZ.
    * Sem o ASI, cai no fallback searchlight/corona sem erro.
    * Ate 16 NPCs acompanhados (budget da API: 64 luzes no total do jogo).
- O INI e lido uma unico vez, na entrada do script (carregar um save). Depois
  de editar, recarregue o save para aplicar.

CONFIGURACAO (CLEO\Jesus Enfermeiro.ini)
----------------------------------------
O arquivo ja vem comentado. Resumo:

  Type = 0               0 = facho, 1 = brilho, 2 = os dois (vanilla)
  Height = 30.0          altura do holofote vanilla acima do NPC
  Radius1 / Radius2      raios do cone (padrao do mod original: 0.0 e 2.5)
  GlowSize = 0.9         tamanho do brilho/corona
  Color = 255 240 180    cor (corona E luz PS)
  OnlyWhenReviving = 0   1 = so acende durante a animacao de reanimacao (CPR)
  MaxLights = 7          searchlights vanilla (7 original; 120 c/ limit adj.)

  UseProperShaders = 1   1 = tenta API do Proper Shaders
  PsType = 0             0 = ponto omni, 1 = spot pra baixo
  PsRadius = 12.0        raio da luz per-pixel (metros)
  PsIntensity = 2.5      brilho (1.0 ~= luz normal do jogo)
  PsOffsetZ = 1.2        altura no corpo do NPC (peito/cabeca)
  PsFog = 1              1 = brilha na fog volumetrica

  [Models]               um NOME de modelo por linha, ex.:
                         LAEMT1
                         SFEMT1
                         LVEMT1
                         NURSE1
                         MEU_PED_ADICIONADO

REQUISITOS
----------
- CLEO 4.4.4 ou superior
- CLEO+ 1.2.0 ou superior (cleo.li) - usado para resolver nome->modelo e para
  percorrer a pool de pedestres. Sem o CLEO+ o script avisa na tela e se
  desliga em vez de dar erro.
- Proper Shaders (opcional) com API 09-26+: ProperShaders.asi

COMPILAR (se mexer no .sc)
--------------------------
    gta3sc "Jesus Enfermeiro.sc" --config=gtasa --guesser -fconst -farrays
           -fbreak-continue -fifnot -flocal-var-limit=32 --cs
           -o "Jesus Enfermeiro.cs"


SE O JOGO CRASHAR
-----------------
O script faz o minimo possivel do lado do jogo (nada de heap walk, nada de
patch de memoria). Mesmo assim, para isolar um crash:

1. No INI, UseProperShaders = 0 e Type = 1: so corona, zero searchlight e
   zero API. Se o crash parar, isole se era PS ou searchlight.
2. Tire o "Jesus Enfermeiro.cs" da pasta CLEO e veja se o crash continua.
3. SCRLog.log (inicio) e ProperShaders.log ajudam a achar o culpado.
